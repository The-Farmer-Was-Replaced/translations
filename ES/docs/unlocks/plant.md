# Planta
El césped es bueno porque crece automáticamente. Todas las demás plantas deben plantarse usando la función `plant()`. La única planta que puedes plantar ahora mismo es un arbusto.

Puedes pasar el tipo de planta que deseas plantar a la función de esta manera:

`plant(Entities.Bush)`

Esto plantará un arbusto debajo del dron.

Llama a `clear()` para restablecer la granja a solo césped y restablecer la posición del dron.

Parece que si cultivas más de un tipo de planta al mismo tiempo en la granja, a veces puedes obtener un mayor rendimiento. Necesitarás investigar policultivo para saber más.
