# Erste Schritte
Dieses Fenster enthält Informationen über alles im Spiel.

Sie können Fenster verschieben, indem Sie den grauen Teil des Fensters ziehen und ablegen.
Sie können sich bewegen, indem Sie überall außerhalb der Fenster ziehen.

Um mit dem Programmieren zu beginnen, gehen Sie zur [Erstes Programm](docs/first_program.md) Seite, indem Sie darauf klicken.
