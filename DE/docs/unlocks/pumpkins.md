# Kürbisse
[Pumpkins](objects/pumpkin) wachsen wie Karotten auf umgegrabener Erde. Das Pflanzen kostet Karotten.

Wenn alle Kürbisse in einem Feld vollständig ausgewachsen sind, wachsen sie zusammen zu einem riesigen Kürbis. Leider besteht bei Kürbissen eine 20%ige Chance zu sterben, sobald sie ausgewachsen sind, daher musst du die toten Kürbisse neu pflanzen, wenn du möchtest, dass sie sich verbinden.

Der Ertrag eines riesigen Kürbisses hängt von seiner Größe ab.

Ein 1x1 Kürbis bringt `1*1*1 = 1` Kürbis.
Ein 2x2 Kürbis bringt `2*2*2 = 8` Kürbisse statt `4`.
Ein 3x3 Kürbis bringt `3*3*3 = 27` Kürbisse statt `9`.
Ein 4x4 Kürbis bringt `4*4*4 = 64` Kürbisse statt `16`.
Ein `n`x`n` Kürbis bringt `n*n*5` Kürbisse für `n >= 5`.

Es ist eine gute Idee, mindestens 5x5 große Kürbisse zu bekommen, um den vollen Multiplikator zu nutzen.

Das bedeutet, dass selbst wenn du in jedem Feld einen Kürbis pflanzt, einer davon möglicherweise stirbt und das Wachstum des Mega-Kürbisses verhindert.
