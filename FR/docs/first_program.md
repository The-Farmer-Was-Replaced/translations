# Premier Programme

## Éditeur de texte

Toute la programmation se fait dans les fenêtres de code. Chaque fenêtre de code correspond à un fichier texte contenant du code.
Vous pouvez renommer le fichier en cliquant sur son nom en haut de la fenêtre.

Le code peut être édité comme dans n'importe quel éditeur de texte tant qu'il n'est pas en cours d'exécution.
Vous pouvez exécuter le programme directement en appuyant sur le bouton vert de lecture dans la fenêtre de code.
![](PlayButton50)

Vous pouvez créer plus de fichiers de code en utilisant le bouton "+" dans le coin supérieur droit de l'écran.
Vous pouvez ancrer une fenêtre à une autre en la faisant glisser dessus.

Vous remarquerez qu'une simple fenêtre de complétion de code apparaîtra dès que vous commencerez à taper.
Appuyez sur Tab pour insérer la complétion de code.
Utilisez les flèches pour naviguer à travers les options de complétion.

Ne vous inquiétez pas si c'est votre première fois en programmation. Le langage est débloqué étape par étape, vous ne serez donc pas submergé par tout ce que vous pouvez faire.
La syntaxe est également similaire à celle de Python, l'un des langages de programmation les plus utilisés au monde, donc l'apprendre n'est pas complètement inutile.

Si vous connaissez déjà Python, ce n'est pas un problème non plus, vous pourrez simplement passer rapidement le début du jeu pour accéder aux choses plus intéressantes.

Le code est une séquence d'instructions qui sont exécutées ligne par ligne.

Actuellement, les seules instructions disponibles sont

`harvest()`

et

`do_a_flip()`

Ce sont des appels de fonction. Une fonction est essentiellement une partie de fonctionnalité qui peut être exécutée. Vous l'exécutez en utilisant les parenthèses `()`.

Essayez de taper ces instructions dans la fenêtre de code et d'appuyer sur le bouton d'exécution.

## Déverrouillages
Récolter de l'herbe vous donnera du foin. Le foin peut être utilisé pour déverrouiller des boucles dans le menu de déverrouillage. Ouvrez le menu de déverrouillage avec le bouton en haut à droite.
