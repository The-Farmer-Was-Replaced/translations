# Citrouilles

[Pumpkins](objects/pumpkin) poussent comme les carottes sur un sol labouré. Les planter coûte des carottes.

Lorsque toutes les citrouilles d’une zone sont entièrement mûres, elles se réunissent pour former une citrouille géante. Malheureusement, les citrouilles ont 20 % de chance de mourir une fois arrivées à maturité, il faudra donc replanter celles qui sont mortes si vous souhaitez qu’elles fusionnent.

Le rendement d’une citrouille géante dépend de sa taille.

Une citrouille 1x1 produit `1*1*1 = 1` citrouille.
Une citrouille 2x2 produit `2*2*2 = 8` citrouilles au lieu de `4`.
Une citrouille 3x3 produit `3*3*3 = 27` citrouilles au lieu de `9`.
Une citrouille 4x4 produit `4*4*4 = 64` citrouilles au lieu de `16`.
Une citrouille `n`x`n` produit `n*n*5` citrouilles pour `n >= 5`.

Il est fortement recommandé d’atteindre au moins une taille de 5x5 pour profiter pleinement du multiplicateur.

Cela signifie que même si vous plantez une citrouille sur chaque case d’un carré, l’une d’elles peut mourir et empêcher la croissance de la méga-citrouille.
