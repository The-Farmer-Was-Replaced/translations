@code_tooltip_harvest = `harvest()`
Récolte l'objet sous le drone.
Si vous récoltez un objet qui ne peut pas être récolté, il sera détruit.

@code_tooltip_range = `range()`
Génère une séquence de nombres.

surcharges:
`range(end)` renvoie une séquence de nombres de `0` (inclus) à `end` (exclusif).
`range(start,end)` renvoie une séquence de nombres de `start` (inclus) à `end` (exclusif).
`range(start,end,step)` renvoie une séquence de nombres de `start` (inclus) à `end` (exclusif) par pas de taille `step`.

prend `1` tick pour s'exécuter.

exemple d'utilisation:
`for i in range(10):
    print(i)

for i in range(2,6):
    print(i)

for i in range(10, 0, -1):
    print(i)`

@code_tooltip_set_execution_speed = `set_execution_speed(speed)`
Limite la vitesse à laquelle le programme est exécuté pour mieux voir ce qui se passe.

Une `speed` de `1` est la vitesse que le drone a sans améliorations de vitesse.
Une `speed` de `10` rend le code `10` fois plus rapide et correspond à la vitesse du drone après `9` améliorations de vitesse.
Une `speed` de `0.5` rend le code s'exécute à la moitié de la vitesse sans améliorations de vitesse. Cela peut être utile pour voir ce que fait le code.

Si `speed` est plus rapide que ce que l'exécution peut actuellement supporter, elle ira simplement à la vitesse maximale.

Si `speed` est `0` ou négatif, la vitesse est remise à la vitesse maximale.
L'effet s'arrêtera également lorsque l'exécution s'arrêtera.

renvoie `None`

prend `200` ticks pour s'exécuter.

exemple d'utilisation:
`set_execution_speed(1)`

Une `size` inférieure à `3` changera la grille en retour à sa taille complète.
L'effet s'arrêtera également lorsque l'exécution s'arrêtera.

renvoie `None`

prend `200` ticks pour s'exécuter.

exemple d'utilisation:
`set_world_size(5)`

@code_tooltip_simulate = `simulate(filename, sim_unlocks, sim_items, sim_globals, seed, speedup)`

`sim_items`: Un dictionnaire mappant les articles aux quantités. La simulation commence avec ces articles.
`sim_globals`: Un dictionnaire mappant les noms de variables aux valeurs. La simulation commence avec ces variables dans le scope global.
`seed`: La graine aléatoire de la simulation. Doit être un entier positif.
`speedup`: L'accélération de départ.

prend `200` ticks pour s'exécuter.

exemple d'utilisation:
`filename = "f1"
sim_unlocks = Unlocks
sim_items = {Items.Carrot : 10000, Items.Hay : 50}
sim_globals = {"a" : 13}
seed = 0
speedup = 64

run_time = simulate(filename, sim_unlocks, sim_items, sim_globals, seed, speedup)`
