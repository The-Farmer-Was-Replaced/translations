# Начало работы
В этом окне содержится информация обо всем в игре.

Вы можете перемещать окна, перетаскивая серую часть окна.
Вы можете перемещаться, перетаскивая любое место за пределами окон.

Чтобы начать программировать, перейдите на страницу [Первая программа](docs/first_program.md), щелкнув по ней.
