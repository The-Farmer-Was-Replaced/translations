# Первая программа
## Текстовый редактор
Весь код пишется в оконных редакторах кода. Каждое окно кода соответствует текстовому файлу с кодом. 
Вы можете переименовать файл, щелкнув по его названию в окне.

Код можно редактировать, как в любом текстовом редакторе, пока он не выполняется.
Вы можете запустить программу, нажав зеленую кнопку воспроизведения в окне кода.
![](PlayButton50)

Вы можете создать больше файлов кода с помощью кнопки "+" в правом верхнем углу экрана.
Вы можете прикрепить одно окно к другому, перетащив его.

Вы заметите, что, как только вы начнете печатать, появится окно автодополнения кода.
Нажмите Tab, чтобы вставить автодополнение.
Используйте клавиши со стрелками для навигации по вариантам автодополнения.

Не переживайте, если вы программируете впервые. Язык разблокируется поэтапно, чтобы вы не перегружались всеми доступными функциями сразу. 
Синтаксис также похож на Python, один из самых популярных языков программирования в мире, так что обучение этому языку не будет напрасным.

Если вы уже знаете Python, это тоже не проблема — вы сможете быстро пропустить начальный этап игры и перейти к более интересным вещам.

Код — это последовательность операторов, которые выполняются строка за строкой.

На данный момент доступны только два оператора:

`harvest()`

и 

`do_a_flip()`

Это вызовы функций. Функция — это, по сути, блок функциональности, который можно выполнить. Для выполнения используется круглые скобки `()`.

Попробуйте ввести эти операторы в окне кода и нажать кнопку выполнения.

## Разблокировки
Сбор травы даст вам сено. Сено можно использовать для разблокировки циклов в меню разблокировок. Откройте меню разблокировок с помощью кнопки в правом верхнем углу.
