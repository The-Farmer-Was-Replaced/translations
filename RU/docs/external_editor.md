# Внешний редактор
Встроенного текстового редактора обычно достаточно для игры, но, конечно, он не может конкурировать с более продвинутыми редакторами, такими как Visual Studio Code.

Игра сохраняет все файлы кода в формате .py, поэтому вы можете редактировать их с помощью редакторов Python. 
Обратите внимание, что это сделано для удобства. Язык игры не является Python, но достаточно похож, чтобы IntelliSense для Python работал корректно.
Файлы можно найти в [папке сохранений](persistent_data_path/Saves).

Каждое сохранение также содержит файл `__builtins__.py`, который включает определения встроенных функций Python, соответствующих встроенным функциям игры, для работы IntelliSense. 
Игра игнорирует операторы импорта Python, так что вы можете добавлять их, чтобы внешний редактор мог распознавать определения функций из других файлов.

Чтобы увидеть внешние изменения в игре без необходимости перезагружать сохранение, необходимо включить опцию "File Watcher". Однако, если вы создаете или удаляете файлы вне игры, для их отображения потребуется перезагрузить сохранение.

## Использование VS Code
Visual Studio Code — это рекомендованный редактор кода для использования с The Farmer Was Replaced.

Вы можете скачать его [здесь](https://code.visualstudio.com/download).

После загрузки установите расширение Python в VS Code.

После этого откройте [папку](persistent_data_path/Saves), где хранятся ваши `.py` файлы, в VS Code. Убедитесь, что вы открыли всю папку, а не отдельные файлы, иначе файл `__builtins__.py` не будет работать.

Расширение Python автоматически не импортирует функции из других файлов, как это делает игра. Чтобы избежать предупреждений `not defined` (не определено) в редакторе при вызове функций из других файлов, вам нужно добавить строку:

`from filename import *`

в начало каждого файла, который вызывает функции из другого файла (замените `filename` на имя файла). Игра проигнорирует эти операторы.

В игре убедитесь, что у вас включена опция "File Watcher". Теперь при каждом сохранении в VS Code изменения будут автоматически отображаться в игре.

Вот и все! Теперь вы можете писать код в профессиональном редакторе кода!
