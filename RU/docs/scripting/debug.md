# Отладка
Иногда ваш код не работает, и нужно выяснить, почему. Есть несколько инструментов, которые помогут вам в этом.

Первый способ — выполнять программу пошагово.
Вы можете войти в режим пошагового выполнения с помощью кнопки рядом с кнопкой выполнения или установив точку останова.

Точки останова можно добавлять, нажав на панель точек останова слева от кода.
![](Breakpoints227)
Когда выполнение достигнет строки с точкой останова, программа автоматически перейдёт в режим пошагового выполнения.

При наведении курсора на переменную отображается её текущее значение.

Функция `print()` также может быть очень полезной. Она выведет любое переданное ей значение прямо в интерфейсе.

Примеры:

`print(0.24) #выведет "0.24"

print(can_harvest()) #выведет "True" или "False"

print(get_pos_x(), get_pos_y()) #выведет текущую позицию`

Функция print() выводит значение прямо в интерфейсе и на страницу [Вывод](docs/output.md).

Вывод в интерфейсе может быть немного медленным, если вы хотите напечатать много значений.
В этом случае можно использовать функцию `quick_print()`, которая выводит только в окно вывода.

Окно вывода также фиксирует предупреждения и ошибки, поэтому, если что-то работает не так, как ожидалось, полезно проверить его.

После завершения выполнения программы вывод также записывается в файл output.txt в папке игры. Вы можете найти папку игры, выбрав Меню -> Загрузить -> Открыть Папку.
