# Словари
Словари — это структура данных, которая позволяет сопоставлять ключи со значениями так же, как настоящий словарь сопоставляет слова с их определениями, и вы можете очень быстро находить нужные элементы.

Словарь можно создать так:
`rotation = {North:East, East:South, South:West, West:North}`

Выражение перед двоеточием — это ключ, а выражение после двоеточия — это значение, которому соответствует ключ.
Приведённый выше словарь сопоставляет направления с направлением, находящимся справа от них.

Вот ещё один пример, который сопоставляет позицию дрона с сущностью, находящейся под ним.
`x, y = get_pos_x(), get_pos_y()
entity_dict = {(x,y):get_entity_type()}`

Доступ к значению, соответствующему ключу, аналогичен доступу к элементу в списке:
`value = dict[key]`

Пример:
`orientation = rotation[South]`
Это присваивает `orientation` значение `West`

Вы можете добавить новую пару ключ-значение в словарь следующим образом:
`dict[key] = value`

Пример:
`entity_dict[(get_pos_x(), get_pos_y())] = get_entity_type()`
Это обновляет сущность, хранящуюся для текущей позиции.

Ключи уникальны, поэтому добавление ключа, который уже существует в словаре, перезапишет предыдущее значение.

Используйте `dict.pop(key)`, чтобы удалить пару ключ-значение из `dict`.

`key in dict` возвращает `True`, если `key` является ключом в `dict`, и `False` в противном случае.
Таким образом, вы можете использовать `if key in dict:`, чтобы проверить, содержит ли `dict` данный ключ.

Цикл `for` по словарю позволяет перебрать все ключи:
`for key in dict:
	value = dict[key]`

Порядок, в котором ключи перебираются, не гарантируется.
