# Функции
Используйте ключевое слово `def` для определения новой функции:
`def f(arg1, arg2 = False):
	#код функции`

Вы можете вызвать функцию с помощью оператора вызова ():
`f(42)`

В отличие от Python, функции, определённые в глобальной области видимости любого открытого файла, можно вызвать по имени, даже если оператор `def` никогда не был выполнен. 
См. раздел [Области видимости](docs/scripting/scopes.md) для получения дополнительной информации.

## Введение
Вы уже видели встроенные функции, такие как `harvest()`.
Вы также можете определить свои собственные функции, что позволяет структурировать код модульно. Это позволяет дать имя блоку кода, чтобы вы могли вызвать его в любом месте.

## Определения функций
Например, вы можете определить функцию, которая перемещает дрон несколько раз:

`def move_n_dir(n, dir):
	for i in range(n):
		move(dir)`

Ключевое слово `def` указывает, что это определение функции.
`move_n_dir` — это имя, к которому привязана функция. Это может быть любое допустимое имя переменной, и оно будет использоваться для вызова функции.
`n` и `dir` — это параметры. Они являются переменными, которые хранят значения, переданные в функцию (эти значения также называются аргументами). Вы можете добавить столько параметров, сколько хотите, в определение функции. 
После двоеточия `:` идет блок кода, который будет выполняться, когда функция будет вызвана.

С вышеуказанным определением следующий код перемещает дрон на `10` клеток на `North` (Север) и `2` клетки на `West` (Запад):

`move_n_dir(10, North)
move_n_dir(2, West)`

## Возвращаемые значения
Используйте ключевое слово `return`, чтобы функция возвращала значение.  
Например, следующая функция определяет операцию исключающего ИЛИ (XOR). Исключающее ИЛИ возвращает `True`, если одно значение равно `True`, а другое — `False`:

`def xor(a, b):
	return a != b

if xor(True, False):
	do_a_flip()`

[Кортежи](docs/scripting/tuples.md) позволяют возвращать несколько значений.

## Значения по умолчанию
Вы также можете присваивать значения по умолчанию, которые будут использоваться, если аргументы не переданы.

`def f(a = False):
	if a:
		do_a_flip()

f()

f(True)`

Аргумент с значением по умолчанию не может следовать за аргументом без значения по умолчанию.

## Расширенное использование функций
Функции — это значения, как и любые другие значения, а оператор `def` действует как оператор присваивания, присваивая функцию тому имени, которое вы ей даёте.  
Это позволяет делать такие вещи:

`def f():
	def d():
		do_a_flip()
	return d

f()()`

Здесь `f()` вызывает функцию `f`, которая определяет и возвращает новую функцию `d`. Второй оператор `()` затем выполняет возвращённую функцию и выполняет переворот.
(Обычно такие вещи не рекомендуется делать, потому что трудно понять, что происходит)

Функции, которые принимают другие функции в качестве аргументов, позволяют быть по-настоящему креативными:

`def f(g, arg):
	for _ in range(10):
		g(arg)

f(move, North)
f(use_item, Items.Fertilizer)`

Этот код перемещает дрон на `North` (Север) 10 раз, а затем использует удобрение 10 раз.
