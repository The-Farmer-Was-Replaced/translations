# Кортежи
Кортежи — отличный способ объединить несколько значений в одно значение.
Чтобы создать кортеж, просто разделите значения запятыми:

`tuple = 1, 2`

Вы также можете "распаковать" кортеж в несколько переменных. В приведённом ниже примере кортеж `(1,2)` распаковывается в две переменные `a` и `b`.

`a, b = 1, 2`

Кортежи могут быть индексированы, как и списки, но они неизменяемы и не могут быть изменены после создания.

`tuple = 1, 2`

`print(tuple[1])`
выведет `2`

`tuple[0] = 3`
выдаст ошибку

В отличие от списков кортежи можно использовать в качестве ключей в словарях.

`d = {(1,2):(4,5)}

print(d[(1,2)])`
`выведет` (4,5)</unlock>

Они также могут быть полезны для возврата нескольких значений в функции.

`def f():
    return 1, 2

a, b = f()`
