# Операторы
Арифметические операторы: `+, -, *, /, //, %, **`
Операторы сравнения: `==, !=, <=, >=, <, >`
Логические операторы: `not, and, or`

Примечание: Все числа в игре — числа с плавающей точкой. Поэтому все арифметические операторы работают с числами с плавающей точкой.
`//` определён как операция деления с округлением вниз до целого числа.

Для использования операторов присваивания необходимо разблокировать функцию "Переменные".

## Введение
Операторы позволяют сравнивать, изменять и комбинировать значения.
Арифметические операторы `+, -, *, /, //, %, **` используются для выполнения стандартных математических операций над числами.
Операторы сравнения `==, !=, <=, >=, <, >` применяются для сравнения значений. Результат всегда равен либо `True`, либо `False`.
Логические операторы (также называемые булевыми) `not, and, or` используются для комбинации логических значений.

## Арифметические операторы
`+` и `-` используются для сложения и вычитания.

`2 + 3` возвращает `5`
`3 - 2` возвращает `1`

`*`, `/` и `//` используются для умножения и деления.

`2 * 3` возвращает `6`
`5 / 2` возвращает `2.5`

`//` делает то же самое, что и `/`, но результат округляется вниз до ближайшего целого числа.

`5 // 2` возвращает `2`

`%` — это оператор остатка от деления, также известный как модульный оператор. Он делит два числа и возвращает остаток. Вы также можете представить это как повторное вычитание правого числа из левого до тех пор, пока остаток не станет меньше правого числа.

`4 % 2` возвращает `0`
`5 % 2` возвращает `1`
`6 % 2` возвращает `0`
`2 % 6` возвращает `2`
`1.5 % 1` возвращает `0.5`

`**` это оператор возведения в степень.

`2**2` возвращает `4`
`(-5)**3` возвращает `-125`

## Операторы сравнения
`==` и `!=` используются для проверки, равны ли два значения (`==`) или не равны (`!=`). Они могут применяться ко всем типам данных.

`2 == 2` возвращает `True`
`Entities.Bush != Entities.Bush` возвращает `False`
`3 != 3 + 1` возвращает `True`

`<=, >=, <, >` могут использоваться только для чисел. Они проверяют, является ли левое число "меньшим или равным" (`<=`), "большим или равным" (`>=`), "меньшим" (`<`) или "большим" (`>`) по отношению к правому числу.

`1 <= 1` возвращает `True`
`2 >= 3` возвращает `False`
`-2 < -1` возвращает `True`
`6 > 6` возвращает `False`

## Логические операторы
`not` просто инвертирует значение:

`not False` возвращает `True`
`not True` возвращает `False`

`and` возвращает `True`, только если оба значения равны `True`:

`True and True` возвращает `True`
`True and False` возвращает `False`
`False and False` возвращает `False`

`or` возвращает `True`, если хотя бы одно из значений равно `True`:

`True or True` возвращает `True`
`True or False` возвращает `True`
`False or False` возвращает `False`
