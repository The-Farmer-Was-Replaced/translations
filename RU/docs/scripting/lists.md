# Списки
Списки — это простой способ хранить несколько значений в одной переменной.
Вы можете создать новый список так:

`list = [2, True, Items.Hay]`

Теперь список содержит значения `2`, `True` и `Items.Hay`.
Список также может быть пустым:

`empty_list = []`

Вы можете получить доступ к элементу списка по индексу. Индекс `0` для первого элемента, `1` для второго, `2` для третьего....

plants carrots
`list = [Entities.Tree, Entities.Carrots, Entities.Pumpkin]
plant(list[1])`

Вы можете перебрать список с помощью цикла `for`. Следующий пример суммирует все элементы в списке.

`list = [4, 7, 2, 5]
sum = 0
for number in list:
	sum += number`
Теперь `sum` равно `18`

Следующие методы списка позволяют добавлять и удалять элементы:

`list.append(elem)` добавляет элемент в конец списка:

`list = [2, 6, 12]
list.append(7)`
`list` теперь содержит `[2, 6, 12, 7]`

`list.remove(elem)` удаляет первое вхождение элемента из списка:

`list = [1, 2, 4, 2]
list.remove(2)`
`list` теперь `[1, 4, 2]`

`list.insert(index, elem)` вставляет элемент по заданному индексу:

`list = [Entities.Tree, Items.Hay]
list.insert(1, Items.Wood)`
`list` теперь `[Entities.Tree, Items.Wood, Items.Hay]`

`list.pop(index)` удаляет элемент по указанному индексу.
Если индекс не указан, удаляется последний элемент.

`list = [3, 5, 8, 25]
list.pop()`
`list` теперь `[3, 5, 8]`
`list.pop(1)`
`list` теперь `[3, 8]`

Функция `len()` возвращает длину списка.
`list = [3, 2, 1]
x = len(list)`
`x` теперь `3`

Списки используют семантику ссылок. Это означает, что присваивание списка переменной присваивает ту же самую ссылку на объект списка, а не делает его копию.
Если две переменные ссылаются на один и тот же список, изменения в списке будут видны обеим переменным.

`a = [1,2]
b = a
b.pop()`
`a` и `b` теперь оба `[1]`
