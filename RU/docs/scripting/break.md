# Break
`break` позволяет завершить цикл досрочно. Когда выполнение доходит до оператора `break`, оно немедленно выходит из самого внутреннего цикла и начинает выполнять код после него.

`for i in range(10):
	break
print(i)`
Этот код выведет `0`, потому что на первой итерации `i` равно `0`, а затем оператор break завершает цикл.

`break` также работает в циклах `while`.

`while True:
	if can_harvest():
		break`

Этот код выполняет цикл `while`, пока `can_harvest()` не вернёт `True`. 
Это окажет такое же действие, как и

`while not can_harvest():
	pass`

Во вложенных циклах `break` всегда завершает самый внутренний цикл.

`for i in range(10):
	for j in range(10):
		break
		print("это никогда не напечатается")
	print("это напечатается 10 раз")`
