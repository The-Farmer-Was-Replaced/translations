# Переменные
Переменные можно рассматривать как именованные контейнеры, которые могут содержать значение.
Оператор `=` используется для объявления переменной и хранения значения в ней.

`variable_name = value`

Левая сторона оператора — это имя переменной. Вы можете дать ей любое имя.
Правая сторона — это выражение, результат которого будет сохранён в переменной.

Объявите переменную с именем `a` и сохраните в ней значение `5`:
`a = 5`
Объявите переменную с именем `b` и сохраните в ней возвращаемое значение `can_harvest()`:
`b = can_harvest()`

Не путайте оператор `=` с оператором `==`. 
Оператор `==` проверяет, равны ли два значения, и возвращает `True` или `False`.
Оператор `=` присваивает значение справа имени слева.

После присвоения переменной вы можете использовать её в коде для получения хранимого в ней значения.

`a = 5
for i in range(a):
	do_a_flip()`

Приведённый выше цикл выполняется 5 раз, потому что `a` установлено в `5`.
Переменная `i` в цикле `for` также является переменной, которая автоматически получает текущее значение последовательности на каждой итерации цикла. (Её не обязательно называть `i`, вы можете дать ей любое допустимое имя.)

Переменные также позволяют выполнить то же самое с циклом `while`:

`a = 5
i = 0
while i < a:
	do_a_flip()
	i = i + 1`

Этот код делает то же самое, что и цикл `for` выше. Мы просто увеличиваем `i` вручную.
Обратите внимание, что для увеличения `i` мы устанавливаем её равной её собственному значению плюс `1`. Изменение значения переменной на основе её предыдущего значения — это очень распространённая операция. 
Её можно сократить, используя эти операторы: `+=, -=, *=, /=, %=`

`i = i + 1` то же самое, что и `i += 1`
`a = a / 3` то же самое, что и `a /= 3`
