# Цикл While
Вы разблокировали цикл `while` и значения `True` и `False`. Цикл `while` выполняет тело цикла до тех пор, пока условие равно `True`.

`while condition:
	#тело цикла`

Не переживайте о создании бесконечных циклов. Задержки в выполнении программы предотвратят её зависание.

## Для новичков
Возможно, вы уже пытались написать несколько вызовов `harvest()` подряд:

`harvest()
harvest()
harvest()`

Это позволяет собирать урожай несколько раз за один запуск программы. 
Однако было бы хорошо собирать урожай больше трёх раз, а писать один и тот же код несколько раз — плохая практика. 
Решение — использовать цикл. 
Цикл позволяет выполнять один и тот же код несколько раз.

Цикл `while` принимает условие, которое является логическим значением и может находиться только в одном из двух состояний: `True` или `False`. 
Такое значение называется булевым значением.

Цикл затем выполняет код внутри себя до тех пор, пока условие не станет `False`.
Цикл `while` выглядит так:

`while condition:
	#тело цикла
	#тело цикла
	#...`
	
Где нужно заменить "condition" на булево значение, а `#loop body` — на то, что вы хотите выполнять в цикле.

Доступны две постоянные булевы величины. Константы — это значения, которые никогда не меняются во время выполнения программы.

Чтобы создать постоянное булево значение, которое всегда будет `True`, просто напишите `True`. Напишите `False`, чтобы создать постоянное булево значение, которое всегда будет `False`.
Таким образом, вы можете написать:


`while False:
	do_a_flip()`

или

`while True:
	do_a_flip()`

Первый пример никогда не выполнит переворот, а второй будет выполнять перевороты бесконечно (бесконечный цикл).

Обычно создание бесконечного цикла — это плохая идея, так как он заморозит программу. Но в этой игре между каждой итерацией цикла есть задержки, поэтому дрон будет продолжать выполнять переворот, пока вы не остановите его вручную, нажав кнопку выполнения ещё раз.

Обратите внимание, что строка после двоеточия имеет отступ. Такие отступы используются для разделения блоков кода.
Нажмите Tab, чтобы добавить отступ, и Shift + Tab (или Backspace), чтобы его удалить.

Цикл повторит все операторы с отступами после двоеточия.
Операторы после блока с отступами будут выполнены после завершения цикла.
