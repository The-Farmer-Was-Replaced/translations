# Области видимости (Name Scopes)
Области видимости определяют, какие переменные доступны из определённого места. Область видимости — это, по сути, отображение имён в значения.
Они работают почти так же, как в Python, но не всегда, поэтому обязательно внимательно прочтите этот раздел.

Как и в Python, существует глобальная область видимости, и каждая функция имеет свою локальную область видимости.
Когда вы объявляете переменную, она добавляется в текущую область видимости.
Всё, что находится вне определения функции, считается частью глобальной области видимости.

`x = 1`
Присваивает значение `1` имени `x` в глобальной области видимости.

Этот оператор `def` присваивает функцию имени `f` в глобальной области видимости.
`def f():
    `Присваивает значение `1` имени `y` в локальной области видимости функции `f`.`
    y = 1

    `Присваивает функцию имени `g` в локальной области видимости функции `f`.`
    def g():
        pass`

`f()`
Вызывает функцию, хранящуюся в `f`, из глобальной области видимости.

`print(y)`
Эта команда печати в глобальной области видимости вызовет ошибку, потому что переменная `y` никогда не объявлялась в глобальной области, поэтому её нельзя прочитать здесь.
Она существовала только в локальной области видимости функции `f`.


Циклы и ветвления не создают собственные области видимости, поэтому всё, что объявлено внутри них, остаётся доступным снаружи.

`for i in range(3):
    pass
print(i)`

Это выведет `2`, потому что последняя итерация цикла `for` присвоила значение `2` переменной `i`.

До этого момента всё работает так же, как в Python. Первое отличие заключается в том, как глобальные определения из других файлов импортируются. В Python для этого используется оператор `import`, а в игре глобальные функции импортируются автоматически.

Любые функции, определённые в загруженных файлах, будут добавлены в глобальную область видимости перед выполнением, поэтому вы можете использовать функции, объявленные в других файлах.
Обратите внимание, что это не относится к глобальным переменным. Они доступны только тогда, когда выполняется строка, где они присваиваются. Выполняется только глобальная область видимости окна, в котором вы нажимаете кнопку выполнения.

Переменные из глобальной области видимости можно читать отовсюду, но присваивания всегда будут относиться к локальной области видимости.

`x = 1

def f():
    x += 1

f()

print(x)`

Этот код выводит `1`, а не `2`, потому что операция `x += 1` сначала читает `1` из глобальной переменной `x`, а затем присваивает `2` новой локальной переменной, которая также называется `x`.
Таким образом, глобальная переменная `x` остаётся неизменной.

Это поведение немного отличается от Python.
В Python здесь будет вызвана ошибка, так как вы пытаетесь прочитать значение из локальной переменной до того, как она была присвоена.

В Python также можно использовать ключевое слово `global`, чтобы указать, что вы хотите использовать глобальную переменную вместо локальной, но в этой игре это не поддерживается.

Если вам действительно нужно обновить глобальные переменные, вы можете использовать для этого словарь.
Словари используют семантику ссылок, что означает, что переменная хранит ссылку на сам словарь, а не саму структуру данных.
Глобальная переменная может хранить ссылку на словарь, который можно читать в функции.
Вы можете изменить содержимое словаря, не обновляя переменную в глобальной области видимости.
Поскольку переменная в глобальной области видимости всё ещё указывает на тот же словарь, она отразит все изменения, внесённые в этот словарь. Для примера рассмотрим следующий код:

Объявление словаря в глобальной области видимости:
`d = {"x": 1}

def f():
    `внесите изменение в словарь, на который ссылается `d`.` 
    d["x"] += 1

`prints `2
print(d["x"])`
