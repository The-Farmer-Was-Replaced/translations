# Расширение 1
Ваша ферма выросла! Однако это пространство будет бесполезным, если вы не можете перемещать дрон, поэтому добавлена новая функция `move()`, которая перемещает дрон. Для `move()` необходимо указать направление, в котором вы хотите переместить дрон. Для этого доступны четыре новых константы: `North, East, South, West`.

Например, `move(North)` переместит дрон на одну клетку на Север.

Если вы переместитесь за край фермы, дрон будет перемещен на противоположную сторону фермы.
Следующий пример кода будет постоянно двигать дрон на Север и возвращать его к началу, когда он достигнет края фермы:

```python
while True:
	move(North)
