# Морковь
Прежде чем вы сможете посадить морковь с помощью `plant(Entities.Carrots)`, нужно выполнить два новых действия. Во-первых, морковь может расти только на вспаханной земле. Чтобы вспахать землю, просто вызовите `till()`. Повторный вызов `till()` изменит землю обратно на `Grounds.Turf`.

Во-вторых, для роста моркови нужны семена. Вы можете купить семена моркови с помощью новой функции `trade()`. 
Передайте тип предмета в `trade()` следующим образом: `trade(Items.Carrot_Seed)`

Если предмет можно купить, он будет куплен.

Вы можете увидеть стоимость любого предмета в его подсказке. Подсказка появляется, когда вы наводите мышь на сам предмет или его название в коде.
