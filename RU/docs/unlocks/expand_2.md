# Расширение 2
Ваша ферма снова расширилась! Теперь клетки больше не выстроены в один ряд, и вам нужно найти способ перемещаться по квадратной сетке.

С помощью цикла `while` это невозможно до тех пор, пока вы не разблокируете способности (senses) и операторы.
Пришло время познакомиться с циклом `for`.

Вы можете узнать всё о цикле `for` на странице [Цикл For](docs/scripting/for), но пока он вам понадобится только для повторения кода фиксированное количество раз.

`#выполнить n переворотов
for i in range(5):
	do_a_flip()`

`range(n)` создаёт диапазон чисел от `0` до `n-1`, содержащий `n` элементов. Цикл `for` выполняет тело цикла один раз для каждого элемента в последовательности. В этом примере `do_a_flip()` будет вызван 5 раз.

Теперь также доступна функция `get_world_size()`. Она возвращает длину стороны вашей фермы. Это позволит вам написать код, который не сломается после следующего обновления фермы.

`for i in range(get_world_size()):
	harvest()
	move(North)`

Этот пример собирает один столбец фермы для любого размера фермы.

Если вы не можете придумать, как перемещать дрон по ферме, посмотрите подсказку ни
<spoiler=Показать подсказку> Существует, конечно, несколько способов перемещаться по ферме.
Мы ищем способ обойти её систематически, чтобы код не сломался после очередного увеличения фермы.
Систематический способ обойти всю ферму — это повторять следующие 2 шага бесконечно:

1.Двигаться `North` до возврата к началу.
2.Двигаться `East`

`for i in range(get_world_size()):` может быть полезен для превращения этой идеи в код.
</spoiler>
<spoiler=Показать возможное решение> Базовый обход может выглядеть так:

`for i in range(get_world_size()):
	for j in range(get_world_size()):
		#выполнить переворот на каждой клетке
		do_a_flip()
		move(North)
	move(East)`
</spoiler>
